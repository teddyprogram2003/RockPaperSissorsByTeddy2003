# Rock Paper Scissors 🎮

A simple Rock Paper Scissors game written in Python.

## How to play

Run the `rock_paper_scissors.py` file and choose:

* Rock
* Paper
* Scissors

The computer will randomly choose an option, and the winner will be determined based on the rules of the game.

## Features

* Player vs Computer
* Random computer choices
* Win, lose, or draw result
* Score tracking
* Option to restart the game

## Requirements

* Python 3.x

## How to run

Open a terminal in the project folder and run:

```bash
python rock_paper_scissors.py
```
